# Hose icon direction study

Built-in image generation, 2026-10-25. Three exploratory directions after the user rejected the chip/chat icon. No direction is approved.

## Prompt

Create ONE art-directed design exploration board presenting THREE distinct premium macOS app icon concepts for "Hose", an application that runs large language models on rented GPU compute. This is a visual direction study, not production assets.
Canvas: wide landscape, warm near-white #f3f3ef background. Three equally sized rounded-square app tiles in a single horizontal row, evenly spaced with very generous whitespace. Each tile roughly 260 px square on a 1536x1024 canvas. No heading, labels, captions, lettering or words anywhere.
Art direction: exceptionally restrained contemporary industrial graphic design, precise geometry, strong recognizable silhouettes, careful optical spacing. Deep forest green, pale jade, warm ivory. Each tile has a softly rounded macOS app-icon silhouette and subtle realistic edge lighting. No chunky clipart.

LEFT concept — COMPUTE FOLD: warm ivory tile. At its center, a single elegant dark forest-green sculptural folded band. Three parallel diagonal segments turn through smooth precise bends to form a compact abstract compute core, reminiscent of layered GPU processing and a flowing model pipeline. One continuous recognizable geometric silhouette, generous negative space. Flat top surfaces, very shallow depth, confident crisp edges. Minimal iconic design.

CENTER concept — MODEL CORE: deep forest green tile. At its center, two thin precisely aligned rounded-square compute wafers floating close together in restrained isometric perspective. Top wafer pale jade, lower wafer a darker jade edge. The top surface contains ONE bold simple ivory flowing S-shaped inset channel, abstracting language passing through a processor. Wide negative space, soft shallow depth, pleasing object proportions. No contact pins, no circuit board, no server imagery. Feels like a beautiful small piece of hardware containing an intelligent model.

RIGHT concept — LINKED INTELLIGENCE: pale jade tile. At center, two bold forest-green rounded angular brackets interlock diagonally around one small ivory diamond-shaped core. They form a balanced compact abstract emblem communicating compute + model connected together. Almost flat, one subtle dimensional bevel, purposeful negative space, easy to recognize at small size.

CRITICAL: All three are elegant brand marks, not explanatory diagrams. Avoid conventional microchip pins, server racks, towers, chat bubbles, document stacks, text lines, brain drawings, sparkles, robot faces, letter h, network graphs, busy details, generic AI knots and stock clipart. Do not add fine outlines. No dramatic glow, glossy plastic, rainbow colors, gradients across the background, decorative objects or heavy shadows. Keep symbols around 55% of tile width so each breathes. Make the three tiles the same visual size. Render as a polished professional identity-design presentation.
